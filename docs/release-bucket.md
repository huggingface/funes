# funes releases

**Durable memory for your AI coding agents.**

This bucket holds the funes installer, released binaries, and checksum manifests. Browse the
version directories for a specific release. The root holds the installer and the latest release
files.

To install funes, follow the [installation instructions](https://github.com/huggingface/funes#get-funes).
